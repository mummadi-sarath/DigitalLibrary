DATA SCIENCE DIGITAL LIBRARY — FRONTEND
========================================

This project includes:
- Homepage and five Data Science syllabus module cards
- Module detail pages and topic lists
- Search across modules and topics
- About page
- Links for notes and important-question PDFs
- No login, password, backend, or database

RUN IT
1. Extract the ZIP.
2. Open the DigitalLibrary folder in VS Code.
3. Open index.html with Live Server, or open index.html in your browser.

IMPORTANT
The five modules are a suggested general Data Science outline, not a verified copy of your college syllabus.
Replace them with your official syllabus if it differs.
Add your PDF files in the materials folder using these names:
module-1-notes.pdf, module-1-questions.pdf, ... through module-5-notes.pdf and module-5-questions.pdf.
